# Pro Git

**Автор:** Scott Chacon & Ben Straub

_Скотт — один із перших співробітників GitHub; Бен — відомий розробник та спікер._

## Опис
Найповніший та офіційний посібник із роботи з системою контролю версій Git.

## Головна ідея
Глибоке розуміння того, як Git зберігає знімки даних, робить вас невразливим до будь-яких merge-конфліктів.
