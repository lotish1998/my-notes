# SQL Antipatterns

**Автор:** Bill Karwin

_Експерт із баз даних, топ-контриб'ютор на StackOverflow у темах SQL та MySQL._

## Опис
Опис типових помилок при проектуванні баз даних та написанні SQL-запитів і шляхи їх вирішення.

## Головна ідея
Помилки в архітектурі бази даних коштують дорожче, ніж помилки у звичайному коді.
