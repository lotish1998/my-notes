# Python Concurrency with asyncio

**Автор:** Matthew Fowler

_Старший програмний інженер, який спеціалізується на високонавантажених асинхронних системах._

## Опис
Повний розбір асинхронного програмування в Python за допомогою модулів asyncio, threading та multiprocessing.

## Головна ідея
Асинхронність дозволяє обробляти тисячі паралельних з'єднань без витрат ресурсів на потоки.
