# Test-Driven Development with Python

**Автор:** Harry Percival

_Відомий розробник, який пропагує методологію тестування Web-додатків з нуля._

## Опис
Посібник із розробки веб-додатків через тестування (TDD) з використанням Django, Selenium та Git.

## Головна ідея
Не пишіть жодного рядка продуктового коду, поки у вас немає написаного тесту, який падає.
