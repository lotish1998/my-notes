# High Performance Python

**Автор:** Micha Gorelick & Ian Ozsvald

_Експерти з Data Science та високопродуктивних обчислень у промислових масштабах._

## Опис
Посібник з профілювання, оптимізації пам'яті та прискорення виконання Python-скриптів.

## Головна ідея
Python може бути швидким, якщо правильно використовувати CPU, пам'ять, асинхронність та Cython.
