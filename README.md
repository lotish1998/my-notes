## Excel Tools

- `excel_to_notes.py` — читає таблицю книг (.xlsx) і генерує окрему
  Markdown-нотатку для кожного рядка, використовуючи назву, автора,
  опис та головну ідею книги.
  Запуск: `python3 excel_to_notes.py data/books_it_py_FINAL.xlsx`

- `photo_to_excel.py` — демонстраційний скрипт, що вставляє фото книг
  (.jpg) у відповідні рядки Excel-таблиці за назвою книги.
  Шляхи в скрипті локальні — наведено як приклад підходу, а не для
  прямого запуску без адаптації шляхів.

- `data/` — вихідна таблиця книг та фото, використані як тестові дані.
